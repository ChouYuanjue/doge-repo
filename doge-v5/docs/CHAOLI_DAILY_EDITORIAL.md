# 超理日报：采编与学术通讯版式

## 定位

本刊报道公开论坛讨论最近24小时内真实发生的论证、问题和新进展；它不等于论坛首页汇总，也不冒充独立核实的研究成果。

官方 #今日活跃 JSON 只用于选取主题。真正的事实依据是逐帖读取后具有楼层号、作者、时间和永久链接的公开正文。引用楼层时严格区分引文与该楼作者的原话。

## 采编过程

1. 起源：从每个主题第一页提取至少前四条楼层，了解原题、主张与主要疑问。
2. 本期：末页倒查近期更新，越过24小时边界再多读一页前情。短帖全部读取，长帖保留起源、历史抽样、相邻前情和当前更新。
3. 证据分层：向编辑模型明确标记 opening_background、historical_context、prior_turn_context、today_update、previously_discussed，避免误把旧帖推导说成今日新成果。
4. 连续报道：若前一天该主题确曾发表带有效楼层证据的日报，将其正文和引用作为差异对照。模型必须说明新变化，不重复昨天文稿。旧的401空白日报不能充当历史基线。
5. 按需补查：模型可以索要最多3个缺失楼层号。服务端只允许检索当前真实主题的数字分页，最多7页/主题、32秒/主题；每期最多6个主题进入一次第二轮采编。
6. 信息密度：文章篇幅跟随本期更新的实质内容，不随历史楼层总数机械增加。纯顶帖、轻量追问写成简讯；具有新论证和不同意见才写成专题。
7. 校验：稿件必须引用存在的真实楼层，有本期更新时还必须至少引用一条当前更新。摘要或PDF失败不会推进发送水位。

每期的清单记录日期、被抓取页面、开头/当天楼层、往期参考、追加补读楼层以及模型真正使用的证据，供人核查。

## 版式

对照了 Notices of the AMS、Quanta 和 EMS Magazine 的出版结构，但没有复制现成模板源码。最终采用独立的 A4 单栏 XeLaTeX 学术通讯，重点适配 QQ 中以 PNG 逐页预览的阅读方式。

结构：正式刊头及期号 → 具体期标题 → 简短全期导语 → 编号、级别和板块 → 各篇标题 → 一句短导语 → 中文技术正文 → 可核实楼层 → 可点击的原帖。正文10.6pt、行距17.8pt，Noto Serif/Noto Sans CJK，中性色与低饱和强调色。

一栏比旧版拥挤双栏便于手机连续阅读；正文自然跨页，禁止强行裁切、不以填满纸面为目标。所有外部内容转义后才进入 TeX，Tectonic 继续使用既有沙箱。

## 限制与验收

论坛删除的楼层、权限限制、纯图片与不可解析内容无法视为完整证据。长帖最多回溯18个最近分页，若无法扫描到截止时间，明确标识覆盖不完整。模型输入最多52条有角色标记的楼层，防止成本失控。

在不向群发送消息、不变更订阅水位的前提下，使用真实论坛数据生成论文式PDF与逐页PNG，并逐页检查中文字体、源文链接、长文段、页码与分页。
